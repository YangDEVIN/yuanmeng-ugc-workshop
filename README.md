# 元梦创作工坊

用于元梦之星 UGC 创作的网页工作台，覆盖地图预览、场景编辑、模型搭建、小游戏原型和工程导出。先在网页中确认布局与体验，再通过工程数据和本机连接工具接入元梦编辑器。

[打开工坊](https://yangdevin.github.io/yuanmeng-ugc-workshop/)

## 可以做什么

- **地图场景**：按玩法类型选择工作区，查看场景、调整布局、设置出生点与环境，保存独立草稿。
- **模型与装备**：预览构件、组合模型与搭配外观，核对比例和资源需求。
- **小游戏原型**：在浏览器验证操作、界面与玩法循环；支持的工程可进一步接入元梦。
- **工程管理**：导入、编辑和导出地图数据，保留布局、玩法配置与验证状态。
- **本机协作**：连接自己的 Agent 和元梦编辑器，核对目标后执行支持的创建、绑定与保存操作。

## 开始使用

线上工坊用于浏览与网页创作。在线版不显示元梦还原、本机连接和本地 Agent 入口。需要这些功能时，下载仓库后运行：

```sh
node tools/serve.cjs
```

打开终端显示的地址，保持服务运行。网页为原生 HTML、CSS 和 JavaScript，使用仓库内置的 3D 库，无需安装前端依赖。

## 统一导出

各地图工作区使用相同的“导出”窗口：

| 选项 | 用途 |
| --- | --- |
| 完整工程 JSON | 保存当前地图布局、编辑信息、环境、玩法及其他工程元数据，供继续编辑和迁移 |
| 元梦放置清单 JSON | 输出当前布局的元件批次、坐标、旋转、缩放和相关配置，供编辑器接入流程使用 |

导出前显示元件数量和坐标单位；发现无效数据时提示原因，不下载错误文件。文件名统一为“地图标识-map-project.json”或“地图标识-placement.json”。下载不执行元梦写入，也不代表机关绑定或实机验收完成。只有示意内容或资源映射不完整的页面，会说明限制。

## 创作与保存流程

选择工作区 → 调整并预览 → 保存草稿 → 导出工程 → 核对元梦目标 → 接入与回读 → 试玩验收。

网页工程和编辑器实例使用不同标识。重新导入时需要重新绑定实际实例；浏览器存档、文件下载、元梦保存和线上发布分别确认。网页预览可能使用近似几何，最终效果以编辑器回读和实际试玩为准。

## 文档与数据组织

- [使用说明](使用说明.md)：通用操作与导出说明。
- [agent.md](agent.md)：制图、数据、安全写入及验收规范。
- [工程格式契约](提示词.md)：JSON 的字段、单位和校验约定。
- 每张地图或游戏在自身目录维护 TASK.tmp.md。确认保存到网页、回读并归档必要信息后删除；后续修改开启新一轮。
- 地图专属设计和验收信息留在对应工程；通用问题与解决方法维护在 agent.md。

## 开发与验证

共享预览、草稿、导出和连接模块位于仓库根目录；静态资源位于 lib/ 等资源目录；本机服务、校验与部署工具位于 tools/。各工程保留独立数据入口。

```sh
node --test tools/test-harness.cjs tools/test-online.cjs tools/test-map-export.cjs tools/test-actions.cjs tools/test-minifigure.cjs tools/test-tab-paths.cjs
node tools/package-site.cjs
```

推送后由仓库部署流程发布静态网站。代码检查、网页操作、元梦单人试玩及多人验证分别记录，未验证的项目不得标记通过。

## 资源与发布

第三方资源保留来源、许可和使用范围；没有公开授权的原模与贴图不随网站分发。本机凭据、用户运行目录和调试缓存不提交到仓库。“元梦之星”名称仅用于说明兼容目标。

## 按页签组织

- maps/fps/：FPS 页面、模板、布局和工程数据。
- maps/story/：剧情页与场景工程。
- maps/parkour/：跑酷页。
- maps/scenic/：观赏页、最新城堡工程及独立场景资料。
- games/blocks/、games/princess/：2D 游戏入口、工程数据、资源与还原包。
- models/animals/、models/minifigure/、models/outfits/：动物、小人和装备预览与数据。

根目录保留首页、共用渲染/编辑/导出模块与兼容跳转页；tools/page-routes.json 记录旧网址到新页签的映射。地图脚本中产生的浏览器地址须依据 document.baseURI，不能按新页签的地址拼接根目录工具页。
