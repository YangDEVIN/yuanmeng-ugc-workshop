# 公主大冒险资源包

解压到可写目录，打开元梦目标草稿并保持 VS Code 元梦 MCP 服务运行。双击「一键还原.cmd」，核对地图后输入 Y。需要 Node.js 22 或以上版本。macOS 或其他系统可在具有相应编辑器和服务的环境运行 `node restore.cjs`。

包内有 24 帧红白机弯道、8 帧公主、5 张物件图、控件布局与 Lua。图片上传到玩家自己的素材库；地图、图层、编程元件、控件和图片编号在导入时取得。

建议使用空白草稿。导入会创建 UI、绑定按键、隐藏对应的原生竞速控件并保存草稿。已有其他玩法脚本时会停止。进度保存在本目录 .restore 下；正常中断后使用同一份解压目录继续，写入回执不确定时请先核对。完成后在元梦中验证开始、跳跃、弯道与通关。
手机横屏使用左侧摇杆，横向拖动控制方向，上下拖动加减速，右手点跳跃。PC 用 A/D 横移、W/S 加减速、空格跳跃，Enter 开始，P 暂停。
