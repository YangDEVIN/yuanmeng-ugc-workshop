# 制图问题知识库

更新：2026-11-23。共 38 类问题。基于当前对话、已跟踪规范与任务记录整理；为问题类别数量，不是发生次数。原因未证实与待验收风险单独标注。

布局 6 类；模型 4 类；数据 6 类；机关 3 类；2D 9 类；验收 2 类；网站 5 类；流程 3 类。

## 使用方式

开始任务先按类别检索相关条目，在项目 TASK.tmp.md 记录适用问题编号、预防动作和验收证据。Agent 只执行本轮授权范围；知识条目不是修改权限。网页调用本机 Agent 时会把本文随规范注入任务。在线知识库仅提供检索，不执行元梦操作。

遇到新问题编辑 knowledge/issues.json，再运行 node tools/build-knowledge.cjs 生成本文和网页；不要将风险条目标为已解决，实际结论保留在各项目记录。统计为去重问题类别，不代表完整历史频次，也不能保证今后零故障。

阶段检查：版本与目标 → 布局/目录/预算 → 数据校验 → 小批回读 → 机关/UI绑定 → 完整试玩 → 保存回读 → 发布验证。

## KB-001 · 场景空旷、建筑堆放杂乱

- 分类：布局；证据状态：用户反馈。
- 症状：场景空旷、建筑堆放杂乱。
- 原因或排查方向：只铺底板和重复摆件，缺少主次与路线。
- 预防与处理：先定出生视线、主地标、广场、环路与功能分区，再按前中远景补细节。
- 验收：从出生点走到每个入口和打卡点，检查遮挡与停留空间。
- 来源：agent.md；项目历史用户反馈。
